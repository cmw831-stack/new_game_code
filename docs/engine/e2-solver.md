# E2 求解器与全构筑穷举的口径

**日期：2026-10-29**

**用途：** 目标 V2 的 E2 要证明或推翻命题 H2“系统上有路”（[持续开发目标](../plans/goal.md)第二、四、五节）。本文件在**运行之前**写定求解方法、构筑空间与各项指标的计算方式；看到结果后若要改，必须在报告里如实记录改了什么、为什么。第五节的通过门槛由负责人 2026-10-29 确认，这里只把它们落成可计算的定义。

## 一、求解器（`src/sim/solver.ts`）

敌人的意图循环与段落抽取都是确定的（种子只决定段落顺序），所以每一局是单人规划问题。

| 项目 | 口径 |
| --- | --- |
| 玩家每轮的选择 | 三种姿态；“含变招”模型另加每战两次变招：暂停一门、本轮优先级（已装备武学的任一其他排列）、本轮留力（0／2／4／6 中与当前不同的值），各配三种姿态 |
| 价值排序 | 先比胜负：胜 ＞ 未分胜负 ＞ 败。都是胜时剩余气血多者优，再比轮数少；都不是胜时敌方剩余气血少者优，再比玩家剩余气血多、撑的轮数多 |
| 轮数上限 | 30 轮（首轮提案）。30 轮结束仍未分胜负记为“未分胜负”，不算胜 |
| 搜索 | 深度优先、带记忆、带下界剪枝：双方气血只减不增（本阶段没有回复气血的效果），所以“本轮就以现有气血获胜”是任何局面的上界，不可能超过已有结果的分支直接剪掉 |
| 去重 | 同一局面的不同决策若结算出完全相同的下一局面，只搜一次；变招余量更多的局面不会更差，所以只保留余量最多的那个 |
| 局面键 | 轮次、敌方随机数状态与段落指针、双方气血／内力／架势／留力／状态／行动序号、变招余量。事件序号、连锁与施放编号只用于记录，不进键；整场事件计数只影响 32,768 的诊断上限，30 轮内达不到 |
| 信息 | 求解器知道全部未来意图（含以后抽到的段落），是**全知最优**，即真人能力的上界。真人只看得到本轮意图和下一项提示 |

**求解器自身的验证**（`test/solver.test.ts`，预期来自朴素穷举：不记忆、不剪枝，枚举全部决策序列）：三套先行构筑 × 三类标准敌人在 7 轮上限（只选姿态）与 2 轮上限（含变招）下结果相同；对拍生成器的 40 局随机开局在 4 轮上限下相同；三种姿态各自的最好结果相同；按最优打法重放得到报告的结果。

**引擎提速：** `runRound` 的工作副本原来整体 `structuredClone`，改成只复制可变部分、共享只读的规则参数与武学定义（每轮约 71 → 15 微秒）。全部测试、2000 局对拍与“预览不改变输入”不变式照常通过。

## 二、构筑空间与对局

| 项目 | 口径 |
| --- | --- |
| 武学 | 先行六门：断势击、归息诀、借力诀、叠寒剑、崩势追击、踏风步 |
| 构筑 | 0–4 门、容量合计不超过 12、铁剑，按优先级顺序区分：共 175 种（39 种组合）；每种配开场留力 0／2／4／6（首轮提案）：共 **700 种** |
| 敌人 | 均衡武者（教学对手）、高架势守卫、蓄震守卫（“非教学敌人”指后两者） |
| 种子 | 1001–1020（与构筑矩阵相同，运行前写定） |
| 玩家开场 | 气血 30／30、内力 10／20、架势 20／20（构筑矩阵口径） |
| 批次 S1 | 700 构筑 × 3 敌人 × 20 种子，**含变招**，无词缀：42,000 局。H2 的判定用这一批 |
| 批次 S2 | 700 构筑 × 3 敌人 × 20 种子 × 无词缀与六个词缀，**只选姿态**：294,000 局。用于 Q16 词缀与关键轮比例；只选姿态是为了控制计算量（含变招每局约 1–2 秒，只选姿态约 0.1 秒） |

每局另跑一次“每轮出招、不变招”的固定打法作对照，用同一轮数上限。

## 三、H2 的四项判定（第五节门槛）

记某构筑 c 对敌人 e 的成绩为（20 个种子中的胜场数，胜场剩余气血之和），按字典序比较。

1. **没有万能解。** 若某构筑对三类敌人都是 20 胜，且每类敌人上的成绩都不低于全部 700 种构筑的最高成绩，它就是万能解。**通过：没有万能解。** 另报告“被支配”的构筑数：存在另一构筑在三类敌人上成绩都不低、至少一类更高。
2. **“一直出招”不是最优。** 对敌人 e，比较“每轮出招”下成绩最好的构筑与最优打法下成绩最好的构筑：前者严格更低，则“一直出招”在 e 上不是最优。**通过：高架势守卫与蓄震守卫两类都成立。** 另报告逐局比较：最优打法能赢、每轮出招赢不了的局数占比。
3. **改一处翻盘率 ≥ 50%。** 单位是最优打法下没有赢的（构筑，敌人，种子）。一处改动：同一位置换成另一门未装备的、加一门（任意位置）、去一门、把一门移到另一位置、改开场留力；改后必须合法。若存在一种改动使同一敌人、同一种子下最优打法获胜，记为可翻盘。**通过：可翻盘的单位 ≥ 50%。** 单槽改良没有计入，所以这是下界；若低于 50%，先把单槽改良加入再下结论。
4. **三种姿态各有不可替代的时机。** 局面是 S1 中每局最优打法所经过的每个决策点。在每个局面上算出三种姿态各自（可配变招）的最好结果；某姿态的结果严格好于另外两种，它就是该局面的“唯一最优”。**通过：出招、架招、调息各自是至少 10% 局面的唯一最优。**

另报告（不设门槛）：**关键轮比例**——最优打法获胜的局里，有一种姿态会把赢变成没赢的决策点占比；变招被最优打法用到的局数和种类；30 轮未分胜负的局数。关键轮要证明“某姿态赢不了”，必须穷尽它的全部分支，计算量是求解本身的两倍多，所以只在 S2 无词缀批次（只选姿态）上算；判定 4 用 S1。

## 四、Q16 词缀（批次 S2）

沿用[词缀矩阵报告](../reports/phase2-affix-matrix-report.md)运行前写定的两条，打法改为只选姿态的最优打法、构筑改为全部 700 种：

1. **改变题目：** 至少一个（构筑，敌人）的胜率比无词缀下降 20 个百分点以上（敌人细则 9.3 节）。
2. **保留解法：** 带词缀的每类标准敌人，仍至少有 2 种构筑胜率 ≥ 80%。

## 五、局限（运行前已知）

- 全知最优高估真人：真人看不到以后抽到的段落。所以“有路”只证明路存在，不证明真人找得到——那是 H3 的事。
- 构筑只含先行六门的组合；单槽改良、卷首残页不在构筑空间里（翻盘率因此是下界）。
- 留力只取四档；S2 不含变招。
