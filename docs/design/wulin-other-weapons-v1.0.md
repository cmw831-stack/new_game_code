# 《武林·自创绝学》刀与棍类设计 V1.0

**日期：2026-10-26（UTC）**

配套 [主计划 V1.7](wulin-self-created-arts-v1.7.md)、[剑类资料 V1.0](wulin-swords-v1.0.md)、[成长经济细则 V1.2](wulin-progression-economy-v1.2.md) 与 [战斗细则](wulin-combat-system-v1.0.md)。本版扩展刀、棍各五品级十二种，和剑合计三十六把武器。

这是一份规则与内容提案，没有编写代码、运行模拟或试玩。每把武器的数值、来源和材料为首轮实验数据；名称可在正式叙事中调整，稳定内容 ID 不随改名变化。

## 一、统一规则和品级

### 1.1 同一套装备边界

只装备一把武器，每把最多一项固定特性；装备容量上限 12，与四门武学共用。三类武器采用相同的品级数量：

| 品级 | 每类数量 | 全部三类合计 |
| --- | ---: | ---: |
| 凡品 | 3 | 9 |
| 良品 | 3 | 9 |
| 精品 | 3 | 9 |
| 名器 | 2 | 6 |
| 神兵 | 1 | 3 |
| **合计** | **12** | **36** |

每个品级、形制和材料的作用都写入该件武器的完整战斗配置，不再叠加免费的品级攻击倍率或附加词条。

### 1.2 价目和材料模板

为让三类武器有同等预算，除教学与保障物品外，刀棍制作直接引用剑类资料中同用途、同容量的矿材配方、耗材费、NPC 服务费、成品售价与回售价。对应关系如下：

| 用途模板 | 参考剑条目 | 适用刀棍 |
| --- | --- | --- |
| 凡品普通制作 | 旧钢剑 | 铁柄刀、短柄刀、长柄铁棍、齐眉棍 |
| 良品均衡 | 精钢剑 | 厚刃刀、拦门棍 |
| 良品续航／灵活 | 轻锋剑 | 追风刀、流水棍 |
| 良品重击／破势 | 厚脊剑 | 破阵刀、伏虎棍 |
| 精品均衡 | 百炼剑 | 赤纹刀、回澜棍 |
| 精品续航／灵活 | 游丝剑 | 游龙刀、连环棍 |
| 精品重击／破势 | 黑铁重剑 | 斩马刀、玄铁棍 |
| 名器路线甲 | 青霜剑 | 赤霄刀、定海棍 |
| 名器路线乙 | 照夜剑 | 断岳刀、伏魔杖 |
| 神兵 | 自铸绝世剑 | 自铸绝世刀、自铸绝世棍 |

套用同模板的明确矿石数量与银两价格已在 [剑类资料第四章](wulin-swords-v1.0.md) 列出，刀棍不另加材料种类、折扣、免费收益或购材加工转卖利润。三类的价值差异来自战斗用途，制作成本不成为某一类的隐性惩罚。

每类凡品另有一件手稿教学训练器具：练功刀、竹练棍及既有木剑。它们绑定教学奖励 ID、不能出售、拆解或返工；Phase 1–2 独立战斗实验室仍只加载铁剑。

### 1.3 战斗效果的共同口径

基础出招的默认气血／架势威力为 4／4，0 内力。每件凡品武器都将自己的最终基础威力写明；未另列基础数值的高阶刀沿用铁柄刀 6／2，高阶棍沿用长柄铁棍 3／5。收费特性仅适用于本类有效的持械攻击，按首次未被闪避的接触结算，每次施放只触发一次。

含内力调整时，先算武学原始费用，再应用武器调整，收费招式最终至少支付 1；随后检查内力、追加攻击留力与连锁限次，最后扣费。已付费后遭闪避不退款；三连不会逐击重复减耗或加成。

武器效果沿用现有气血、架势、格挡、护势、破绽、寒意、格挡事件、反击窗口与触发预算。不增加距离格、弹药／弹数、出血条、连击计数器或额外免费基础行动。不同刀棍威力仍先修正，再经过既有格挡、当前资源上限与死亡顺序。

## 二、刀：气血伤害与兑现时机

刀的基础动作偏向更高气血威力、较低架势压力；付费招式也更多把预算放在气血与执行时机。它保留四武学位、共同容量及剑类同额的工艺价格。刀与剑的差异来自对现有威力、费用和目标状态的修正，二者不共享品种 ID。

### 2.2 刀与现有武学的兼容

刀类攻击可装备断势击、崩势追击、持械借力反击等通用持械动作，以及已研究的五槽自创招。叠寒剑、逐影刺保留 `swordOnly` 条件，不能由改名刀自动使用。内功、身法、心法全局组件仍可装配，但须通过现有标签兼容和容量检查。

断岳刀的加成检查该击前架势；同一击刚打崩的架势不能倒算。赤霄刀检查该击前气血，武器伤害不能先把目标打进半血再追溯获得加成。特性虽在接触结算，前置状态一律锁定在该次首接触计算前。

## 三、棍：架势控制与防守反击

棍的基础动作偏向架势压力、守势和反应，气血威力较低。护势由实际选择的基础架招准备，不赠送额外基础攻击；棍的专有收益必须以实际格挡、减少架势损失或产生反击为条件。

“减少气血伤害”按实际前后损失差计算。若攻击被闪避、护势无效、玩家内力已满，棍的触发不能虚发格挡、减伤或回气事实。攻击者架势损失仍依既有上限、崩溃每轮一次、破绽一次消费与死亡规则处理。

伏魔杖是一个工艺配置，架招回复 +4 与随后守反效果必须按同一武器容量／来源定义；不再叠加剑类的首击伤害、随机招架或另一个武器位。

### 3.2 棍与现有武学的兼容

棍可装备断势击、崩势追击、借力诀反击等兼容的通用持械动作。专用剑招仍要求 `swordOnly`，不由棍标签自动改名。格挡、防御准备和回气类武学可正常与棍配合，前提是容量、起势与收费合法。

棍的强项靠玩家选择架招与读取敌人意图兑现。没有选择架招或没有发生有效格挡时，棍的防守特性不触发；不会同时获得一次免费的普通攻击。基础攻击仍是一项单击，游戏不加入距离、扇形击中多人或新增连击条。

## 四、品级、许可与交付阶段

### 4.1 每类武器独立成长

每类凡品的教学、入门、进阶、名器、神兵各有自己的稳定配方许可和课题 ID，不用刀的完成记录替代棍或剑的类别精通。武学知识、锻造技艺和武器许可仍分别保存。

| 品级 | 每类解锁方式 | 防止循环与软锁 |
| --- | --- | --- |
| 凡品 | 对应课堂入门及普通成品货架 | 教学器具唯一；所有原料可补买或重复采集 |
| 良品 | 在同类别公开课题使用已有凡品完成一次验证 | 验证不要求先持有良品；配方永久保留 |
| 精品 | 用同类别良品赢下一项公开敌人挑战 | 挑战可用代工、成品或本人制作的良品通过 |
| 名器 | 同类别特殊课题与现有医案／人物或战斗观察衔接 | 不要求收齐本类别低品级，也不消耗唯一许可 |
| 神兵 | 保存合法自创秘籍、验证同类别任一名器、通过综合论艺 | 不要求另外两类名器或全部三十六把；综合论艺可用适配的低价配置 |

所有课题正式编入时必须先列公开前提、固定对手配置、收益和唯一结算记录。同一种武器的重复购买、改名和读档不能重新授予许可、奖励或重复材料包。

制作允许在指导下自制或提供矿材请锻师协作。协作可取得物品与推进器物故事，不计为玩家独立锻造熟练；锻造熟练仍沿用生活技艺自己的证据。

### 4.2 对现有刀棍名器课题的限定

刀的名器题要求的“目标半血”“目标架势为零”等状态均指首接触前快照；高架势／蓄震敌人的详细血量与意图见[敌人配置表](wulin-enemies-v1.0.md)，相关课题仍需按完整输入验证可达性。刀的高伤害不能靠添加出血条或延长战斗外状态兑现。

棍的守势课题需预先给出可预计的敌方主招与可行回应，能够使用架招、护势及现有格挡反击武学完成。它不要求有免费神兵、玩家一定精通医术，或唯一故事角色反复受伤。

这二十四种设计沿用剑类的十二种固定容量预算、三种矿材、返工／成品防套利规则和仅一次的材料礼包。若其价格或容量与用途模板不同，须先在完整武器预算表重算，不能添加免费的品级面板。

### 4.3 完整品种范围与阶段验收

| 阶段 | 首批交付 | 必须验证 |
| --- | --- | --- |
| Phase 1–2 | 铁剑；实验室不强制刀、棍 | 原十二门战斗输入、留力、格挡与铁剑手算保持 |
| Phase 5 | 三类凡品、良品，共 18 种 | 三种基线差异真实影响构筑；刀、棍入门题可由铁剑或凡品通过 |
| Phase 6 | 三类精品、名器、神兵，共 18 种 | 两种名器风格各自成立；神兵不要求三类集齐；36 个 ID、许可和保存都一致 |

36 是新增的完整 MVP 内容目标，不等于现有剑细则已实现，也不代表任何装备已经平衡。品质系数、胜率、敌人完整输入和实际制作量均待模拟与试玩检验。

## 五、设计检查清单

- 剑、刀、棍各有 12 种独立 ID，数量分别为 3／3／3／2／1；类别变化不能只替换名字。
- 剑按状态触发，刀偏气血结算，棍偏架势／守势与反击；同材料、容量条件下能明显说明区别。
- 刀的血量阈值与名器效果读取接触前状态，不会先击伤再追溯加成。
- 棍的被动格挡必须真实减伤或实际损失架势；回气要求当前内力未满、每根最多一次。
- 架招占用基础行动；棍不因防守配置多发一击，不双计格挡、架势回复或破绽。
- 兵器费用修正与十二门内功回气、留力底线顺序一致；不能出现零费收费招或借用尚未发生的回气。
- 名器、神兵都允许用可达的既有武学与对手取得；神兵每类每档一件，三类最多三件，单类神兵不要求收齐其他两类。公共工艺赏金和三档材料包按全存档去重，不按类别重复发。
- 旧Sword资料、剑类ID、36总目录、成长经济、损失规则、素材价格和README都指向同一版本。
