## 二、玩家实际玩什么

### 2.1 一场战斗的循环

战前编排四门武学 → 看本轮敌招 → 选择出招、架招或调息 → 自动处理双方行动与武学连锁 → 看清关键收益和损失 → 选择下一轮，或战后改良。

自动的是武学执行与连锁，玩家仍有基本战术选择。普通敌人可使用自动策略快速处理，精英与首领可以逐轮操作；两种方式使用同一规则，不给自动模式额外属性。

### 2.2 相比 V1.2 的明确调整

| 原提案 | 本版采用 |
| --- | --- |
| 基础行动平时自动，战中主要依赖两次干预 | 每轮可免费选择基础姿态；自动模式可选，两次变招用于临时调整编排 |
| 守势何时生效不够明确 | 轮初承诺后提前建立守势，占用本轮基础行动，不因排后手而来不及防御 |
| 破绽轮末到期 | 保留至制造者下一次新实例基础行动及其连锁结束，或被合格攻击消费 |
| 默认普通命中起势排除格挡 | 基础攻击实际接触，包括格挡，都可触发默认起势；完全闪避不触发 |
| 概率防御和暴击边界仍待定 | 首轮不设常驻随机失误、闪避和暴击；身法与防御来自明确状态，概率组件后续单列 |
| 逐事件队列影响多门武学竞争资源 | 明确拆招窗口，出手方跨武学候选综合按编排排序；不让隐含事件顺序代替玩家优先级 |
| 可选追击的保留资源规则未冻结 | 提供一个“追加攻击留力底线”，付款后低于底线的自动追加攻击跳过 |

### 2.3 一场普通战斗的调优方向

先以约 6–10 轮作为普通战斗的节奏目标，首领可以更长。玩家应在少数关键回合改变计划，不需要逐项点击每次攻击。时长、轮数和界面负担都须通过试玩校准。

后文的低血量算例用于核对规则，不能当作已经达到正常战斗节奏的证据。

## 三、构筑与资源

### 3.1 战前限制

- 最多 4 门武学，外功、内功、身法与心法共用位置。
- 总容量首轮为 12。完整模板和自创秘籍遵守同一价目与兼容规则。
- 一把剑／刀／棍，最多一条固定特性；三类各五品级十二种按完整配置占容量 0–4，轻锋／厚脊的轻量／配重仍各占 2，铁剑占 0。
- 一件采集工具、两剂药品沿用生活计划。药品先限战间，不在战斗中插入无限喝药动作。
- 每门武学可安排优先级；一场战斗中不临时换书、换兵器或重编五槽。

具体修正见 [剑类资料](wulin-swords-v1.0.md) 与 [刀棍资料](wulin-other-weapons-v1.0.md)：收费特性按施放而非逐击计算，先修正费用再检查内力和留力。木剑、旧钢剑另有明确的零费基础出招配置；其他剑的基础出招保持默认。已有手算中的无特性朴剑即铁剑，不自动套用新兵器；旧轻剑、重剑对应轻锋剑、厚脊剑。

### 3.2 三项战斗资源

| 资源 | 规则 |
| --- | --- |
| 气血 | 降至 0 立即败退，停止剩余攻击与治疗收益循环 |
| 内力 | 实际发动前支付，不透支；回气不得超过上限 |
| 架势 | 承受打击压力，降至 0 时崩溃；影响格挡并产生破绽 |

破绽、护势、身法准备和寒意都采用有限状态，不增加另一条常驻资源槽。最大气血／架势按对局配置；内力上限可先用 20 进行实验。

### 3.3 留力底线

玩家可设置一个追加攻击留力值，例如 4。自动追加攻击付款后若会低于 4，则跳过此次机会。该限制包括额外攻击、反击和追击，不影响零费基础攻击，也不阻止回气或必要防御技能使用所留资源。

检查时只看付款后的现有内力，不提前借用未来可能命中的回气。例如现有 6、追击花 3，即使它命中能回 2，在留力 4 时仍会跳过。

记录应区分“内力本身不足”和“低于留力底线”。没发动不扣费，也不触发收势。已出手后被闪避仍支付成本。

## 四、每轮时间与三个基础行动

### 4.1 轮次流程

1. **显示敌招。** 敌人先确定本轮基础意图及公开的条件反应，不在玩家选择后暗改。同时显示当前套路段落、本段剩余意图、已抽定的下一段落和本场词缀。
2. **玩家选择。** 选择出招、架招、调息或由自动策略代选，可使用剩余变招次数。
3. **共同准备。** 锁定输入；检查待执行的冻结跳过；未被跳过的架招提前提交护势，并记为本轮基础行动已经使用。双方准备状态先提交，再按公开顺序结清各自准备所生的连锁。
4. **轮初恢复。** 双方各恢复 2 内力至上限，处理真实增加产生的边界连锁；双方数值先更新，再按公开先后顺序处理响应。
5. **基础行动。** 首个原型固定玩家先手；执行每个尚未使用的出招或调息前，再检查最新冻结与保护状态，处理准备之后新施加的控制；未被跳过的行动及其整根连锁依次完成。
6. **轮末收束。** 处理到期、崩溃恢复和结算记录，所有待决变化与收势结束后进入保存边界。

基础行动先后和自动响应先后是不同概念。初版不增加速度条；以后如引入敌人先手，必须提前显示，不回退轮初已经建立的防御。

### 4.2 基础行动首轮数值，默认铁剑

| 行动 | 主要结果 | 代价 |
| --- | --- | --- |
| 出招 | 普通一击：气血伤害 4、架势伤害 4；适用时可消费破绽变为气血伤害 6 | 占一次基础行动，0 内力 |
| 架招 | 恢复 4 架势至上限，建立一层本轮护势 | 占本轮基础行动，不再自动送一次普通攻击 |
| 调息 | 在自己的行动窗口恢复 4 内力至上限 | 占一次基础行动，承受对手本轮行动风险 |

轮初自然恢复与调息是两笔不同的资源变化，均可核对；实际没有增加时不发送回气事件。

### 4.3 自动策略

保留少量简单预设，例如优先出招、低内力时调息，以及面对已知重击时偏向架招。玩家可在合法窗口暂停自动，接管下一次选择，不抢动画帧。

自动策略记录实际选择，重放时使用该记录。它不是会隐藏读取未来敌招的最优解工具，也不直接替玩家给所有构筑评分。

### 4.4 每战两次变招

每战暂有 2 次，在尚未承诺的一轮临时做一项调整：改变本轮武学优先级、暂停一门可选武学，或调整本轮留力值。效果到轮末结束，原秘籍与长期编排不被改写。

基本攻守调息选择不收费。变招不额外赠送攻击、不返还已付内力，也不允许修改已经结算的回合。

## 五、命中、防御与状态

### 5.1 确定性为初期默认

在没有声明防御效果时，攻击按接触处理。首轮没有基础命中率掷骰、常驻随机闪避或随机暴击。战斗随机数只用于在段落交界抽取敌人的下一套路段落，抽取时点与公开方式见[敌人细则](wulin-enemies-v1.1.md)第 2.2 节；它不进入任何命中、伤害或触发结算。

闪避由明确的身法准备提供：避开下一次打击，随后消费。多段主招仍会继续处理剩余打击，因此闪避一击不等于闪掉整组连击。完整六种起势中的“闪避成功”可由这些身法规则产生，不因降低随机性被取消。

暴击或概率效果以后若加入，需独立声明条件与概率，并更新预览及随机数契约；不把理论最高伤害当作必然结果。

### 5.2 护势与格挡

护势最多一层，在下一门敌方主招首次出现未被闪避的打击时，锁定为该主招使用。在本招内，只要击前仍有架势且本轮没有崩溃，各击最终气血伤害为修正后威力乘 0.5 再向下取整；架势伤害仍完整承受。该门主招结束后消费这层护势；若整门主招都被闪避则不消费。

某一击使架势崩溃时，这一击仍按击前的格挡处理，后续打击失去格挡。身法先躲开的打击不消耗护势。

同类状态已经存在且无合法增量时，支付前跳过，不扣费、不占成功限次，也不重扫同一旧事实。纯回气内力已满时同样跳过；复合动作只有全部效果都无增量时才跳过。攻击发动后被闪避仍照常付费并占次数。

基础架招提供的护势到本轮末过期。技能提供的护势／身法准备默认到下一轮末过期，或提前被消费；同类最多一层，重复无效添加不叠层、不刷新现有期限，也不反复发送新事件。

### 5.3 一次打击的顺序

1. 确认来源、目标和本招仍合法。
2. 有有效身法准备则先闪避，此击没有气血／架势伤害及接触型劲力。
3. 否则确定是否格挡、是否使用本击允许消费的破绽，并计算本击伤害。
4. 提交实际气血与架势变化，记录接触、格挡和实际受伤。
5. 气血为 0 时立即收束战斗，不再让尸体回气、反击或额外叠状态。
6. 对仍在场目标处理崩溃、接触型劲力与阈值变化，记录不可变的结果事实。

伤害先依据主招与明确修饰形成整数威力，再套格挡倍率，最后限制到目标当前气血。吸血等将来启用时只按实际气血损失记账。

### 5.4 接触与触发语义

- 默认“自身基础攻击命中”起势接受基础出招的实际接触，包括格挡后的接触。
- 完全闪避不算接触；反击、自动主招和追击也不自动冒充基础出招。
- 组件可明确要求“未被格挡”或“造成实际伤害”，代价与收益单独计价。
- 寒劲等接触效果按本门主招每击计算，不因其起势每根只发动一次就漏掉后两击。
- 受伤事件只在实际扣血时产生；回气事件只在实际内力增加时产生。
- 状态消耗与移除不冒充新施加；无效刷新不生成新的收益机会。

## 六、架势崩溃与破绽

架势从正数降到 0 时发生崩溃，每名角色每轮最多一次。本轮崩溃后不能继续格挡，单纯恢复一点架势不绕过这个标记；其他明确被动仍可运行。

崩溃创造一份破绽，归属于制造者。可利用窗口为：当前根连锁，以及制造者下一次新实例基础行动和它的连锁结束之前。“下一次”按行动实例区分，无须切换行动类型。反击制造破绽的人也有机会在下一次出招兑现。

若制造者下次选择架招，窗口在共同准备阶段完成自身架招及其连锁后结束，不拖到对手出手之后；下一机会被冻结跳过时也算已经用掉这个窗口，不可无限留存。

基础出招可消费破绽获得示例额外 2 点威力；指定重击／追击也可以消费，具体收益由组件声明。一份只能由第一项声明可消费的合法接触使用，普通多击不会无收益地吞掉破绽：闪避时不消费，被格挡但发生接触时仍可消费并正常减伤。

新的崩溃不叠加第二份破绽，也不刷新未消费窗口的期限。刚刚制造破绽的那一击不追溯获得额外伤害。

轮末让本轮崩溃、仍在场角色的架势至少恢复至上限的 40%（向下取整），不降低已经恢复得更高的值。架势恢复不等于破绽到期，不触发第二次崩溃。破防本身不直接秒杀。

## 七、寒意、冻结与行动窗口

沿用生活计划的有限控制：寒意正常最多 3 层，达到阈值后清空并冻结一次。敌人词缀“寒体”会公开把阈值与正常上限改为 4，冻结保护期间的上限相应改为 3。

冻结跳过下一次尚未执行的基础行动，不撤销已经完成的攻击或轮初架招。若本轮基础行动已经使用，作用于下一次机会。

冻结不禁止明示的被动反震、格挡和反击。跳过一次后，目标获得一个不再被同类冻结跳过的基础行动窗口；从冻结施加到该保护窗口结束，寒意上限暂为 2，结束后才可重新正常跨到 3。

这使寒霜流能够控制节奏，同时仍要承受被动反应和对手保留的行动机会。将来加入其他控制时，必须补统一的行动窗口规则，不靠堆不同控制名称制造永久失去行动。

## 八、武学如何接招

### 8.1 五段组件的职责

| 段落 | 主要职责 |
| --- | --- |
| 起势 | 监听一个明确事实并获得发动机会，区分双方和基础／追加攻击 |
| 主招 | 支付后执行有限打击、防御准备或资源动作 |
| 劲力 | 只修改声明范围内的本招效果，不免费影响所有武学 |
| 变化 | 根据对应结果执行子招，独立计费，不递归继承整套父武学 |
| 收势 | 在对应主招或子招结果确认后结算，未满足条件不返气 |

允许明确的“无劲力／无变化／无收势”中性选项，它们不另计一门武学或一种有效内容。单槽改良与完整五槽自创仍分别交付。

### 8.2 先拆招，再完成本门武学，再跨武学联动

完整次序为：

1. 主招内部逐击记账，记录接触、受伤、崩溃与状态等事实；不在动画中随机插招。
2. 主招结束，先给受击方一个防御响应窗口。其符合条件的回气、反震、反击等按该方编排排序，执行前检查资源与次数。
3. 防御响应结清、原出手者仍能继续时，处理本门武学声明的变化。
4. 对应子招结果确认后，结算本门收势，再记录正常完成。
5. 汇总本门主招、变化和收势产生的事实，将出手方其他武学的候选按其编排排序，继续自动接招。若本门本身正在一个已排定的响应批中，新候选先缓冲，等原批全部处理后再构成下一批；攻击引起的对方拆招窗口仍及时结清。

同一门已经发动的武学先完成自己的结构，不因其他书排名较高就半路跳过其自带变化。变化子招默认只执行自身声明的动作与效果，不继承父招的起势、变化和收势；额外复制劲力也需要明示与计价。

子招仍允许目标拆招。子招结束后，出手方跨武学联动合并到父招的候选批次；防御响应则及时处理。实现时用显式工作队列／待决施放记录表达，不用无限递归调用。

### 8.3 优先级与资源竞争

同一响应窗口里，一方的候选可以来自该主招的不同事实，统一按武学优先级、装备位、稳定规则 ID 排序。不能因为内部先记录了一个事件，就让低优先武学永远抢走高优先武学的内力。

同一规则匹配同一批的多条事实时先合并，保留可解释的原因。执行前重新检查目标、资源、留力和限次；旧事实不因后续回气被回头反复扫描。

例如受击方原批已排好归息、借力：归息回气产生守拙的新机会，守拙放入下一批，不插到本批尚未处理的借力前面。优先级控制同批顺序，不追溯改写已经锁定的响应批。

防御响应与自己的跨武学接招是不同窗口。把己方追击排到第一位，也不能取消对手已经合法获得的拆招机会；想避免反震，需要改造主招、建立防御或让本次主招直接结束战斗。

自我回复和增益只产生本人的资源／状态事实，不凭空建立一个“被攻击”窗口。

### 8.4 连锁限制

- 一次基础行动或明确边界效果建立根连锁，双方所有派生招式沿用它。
- 同一角色、武学实例、组件规则在一根连锁中默认最多成功自动发动一次；四门相似武学不能误共享同一个限次键。
- 单次已付款主招的三次打击仍完整执行。多次发动组件若以后开放，另行标价与测试。
- 初期回气类内功额外每轮最多成功发动一次；无实际增加也不发送新回气事实。
- 同一事件实例不反复触发同一规则；支付失败不扣钱或伪造完成，新的合法事实才可能产生新机会。
- 保留每根 128 事件、每轮 512、每场 32,768、深度 16、最多 100 轮等诊断上限，数值待测。

执行上限是最后保护。超限取消未执行变化与收势，已付费用不回滚，不能靠触顶自动获胜；正常构筑频繁触顶应视为设计缺陷。

## 九、初始内容与三种构筑

### 9.1 八种主招原型与四种劲力

八种主招可先统一为单击、连击、重击、破势击、护势准备、身法准备、回气、反击。参数化的两连／三连属于同类动作，不按不同次数重复计数。

四种劲力保持刚、柔、寒、震：分别偏向伤害、以输出换取防御收益、积寒、以代价强化架势压力。每项有明确适用标签，不让纯回气动作免费附带寒劲攻击。

[组件细则](wulin-components-v1.1.md)已提出发动费用、容量、次数与离散参数的统一价表，下列十二门总价可逐项重建；完整模板、改良和自创走同一预算。条件起势的 −1 费用在起势栏公开，费用下限和兵器修正依统一顺序处理。数据仍待平衡验证，不给模板额外特价。

## 十、敌人怎样提供不同问题

完整输入、敌方武学、公开套路段落、词缀、五类标准版与论艺版、奖励和成长挑战见[敌人设计 V1.1](wulin-enemies-v1.1.md)。该细则补齐本章的首轮配置提案，不代表已经通过模拟或试玩。

| 敌人模板 | 明牌威胁 | 现有应对方式 |
| --- | --- | --- |
| 均衡武者 | 基础攻击、架招与调息交替 | 学习完整回合与资源循环 |
| 高架势守卫 | 较高架势与有节奏的守势 | 破势投入、合适的重兵器、选择出招窗口 |
| 蓄震守卫 | 对一门多段主招，完成后按有效接触数反震一次 | 降低连击、换单次重击、通过身法／护势准备承担反应 |
| 疾步剑客 | 预告的身法准备与回补空窗 | 基础一击消费准备后，在公开空窗出招；也可改用格挡反击等起势 |
| 蓄力刀客 | 提前显示高伤主招及其资源代价 | 轮初架招、控制其尚未执行行动，或在其调息时进攻 |

首轮不用整套绝对免疫。蓄震每根连锁最多一次，且依赖自身仍在场与有足够内力；冻结不取消它的明示被动。

疾步的一份准备只避一击；但基础攻击若完全闪避，确实不能启动接触起势，不会凭空接三连。因此本敌人不连续每轮回补准备，行为周期必须包含至少一轮公开、无身法准备的进攻窗口。其身法仍需按相同武学费用与次数取得，不免费无限刷新。

敌招一经展示，不读取玩家尚未承诺的选择再改变。镜像所用秘籍是独立快照，不因玩家之后编辑同名秘籍即时变更。

## 十一、手工核对用例

以下只是规则演算，不是程序测试或试玩结果。初始资源已经包含本轮自然恢复，避免重复加 2。

### 11.1 寒霜与破势同根联动

玩家用朴剑，叠寒剑容量 6＋崩势追击容量 4，共 10／12，留力为 0。玩家气血 30、内力 10；敌方气血 30、当前／最大架势 10，本轮准备普通出招，无额外防御。

| 步骤 | 玩家内力 | 敌气血 | 敌架势 |
| --- | ---: | ---: | ---: |
| 初始 | 10 | 30 | 10 |
| 基础出招，伤气血 4／架势 4 | 10 | 26 | 6 |
| 叠寒剑付款 4，三击各伤气血 3／架势 2 | 6 | 17 | 0 |
| 三次接触积满寒意，清空并冻结；崩溃产生一份破绽 | 6 | 17 | 0 |
| 崩势追击付款 3，消费破绽，造成气血 6 | 3 | 11 | 0 |
| 确认实际造成气血伤害，收势回气 2 | 5 | 11 | 0 |

该根总伤害 19、实际付款 7、恢复 2，净耗内力 5。敌方本轮尚未执行的基础出招被跳过；轮末架势恢复到 4，不能凭冻结抹掉其他合法被动。

### 11.2 相同构筑选择留力 4

叠寒剑付款后剩 6，仍满足底线；崩势追击付款后只剩 3，因此跳过，不消费破绽，也不发放收势回气。

结果为敌气血 17，玩家内力 6，仍有一份未消费的破绽。玩家少打了 6 伤害，但保留更高现有内力及下次基础行动的兑现机会。这不是“内力不足”，而是玩家主动选择的资源保护。

若双方存活并进入下一轮，单计自然恢复，两案内力分别是 7 与 8；留力案的未消费破绽仍在其下一行动结束前有效。这只证明存在取舍，不证明多留 1 点内力就值得少打 6 伤害。需要结合后续防御成本、击败时机与至少两轮结果调优，不能把留力默认设成必选的正确答案。

### 11.3 同一三连面对蓄震守卫

守卫明示：一门多段主招完成后，以有效接触数反震一次，每次接触示例贡献 2 伤害，发动费用 2 内力；自身内力足够。

三连后先结算受击方反应：它反震 6，再轮到玩家的后续接招。若玩家气血起始 30，则降至 24；若当时只剩 6，则先败退，崩势追击不再付款或执行。冻结不阻止这次被动。

这让玩家有理由改主招、准备防御或降低连击，而不是给守卫永久免疫寒意。

### 11.4 防反的另一条账本

玩家只装归息诀与借力诀，内力 2、气血 30、架势已满 20，选择架招。敌人气血 30／架势 10，本轮出招威力为气血 8／架势 6，无后续特殊反应。

格挡后玩家损血 4、架势降到 14。归息优先回气 2，内力到 4；借力再付款 3，反击造成敌气血 6／架势 2。结果为玩家气血 26、内力 1、架势 14，敌气血 24／架势 8。

如果对手本轮没有攻击，玩家不会白得格挡回气和反击收益，需要在下一轮考虑主动出招或调息。

## 十二、预览、记录与学习

敌人面板显示基础意图、主要数值、已经公开的反应及次数。每项威胁至少能对应一种现有手段；没有应对选择的信息展示不能单独提供策略深度。

首轮确定性规则下，相同本轮输入的预览应与实际结果一致。未来加入概率时，明确区分确定部分、条件部分和随机部分，不把全部理论追击算入必然伤害。

预览使用战斗状态副本，不扣内力、物资或研究，不推进正式随机数，不偷看未公开的未来敌招。

默认记录只突出：谁先出手、哪门武学接上、谁花掉内力、破绽由谁消费、追击为何停。详细记录再展开父事件、施放实例与资源账本。播放快慢和特效开关不改变同输入结果。

## 十三、与生活养成衔接

气血和内力在连续遭遇间按实际状态延续，不默认每战后回满。有限休整与药品帮助玩家继续深入；基础归馆休整仍提供不被资源锁死的退路。

当前首轮成长输入固定玩家最大气血 30、内力 20、架势 20；新遭遇架势回满并清理上一场战斗状态。实验室和规则算例可以有明确不同的初始输入，不能将模拟状态写回历练或凭研究等级免费提高上限。

兵器工艺提供有代价的选择，不能覆盖全部弱点。医术和药品先用于战间或人物事件；它们只更新历练资源，不直接派发本场战斗的回气、受伤或反击事件。

冒险结束仍保留长期技艺、秘籍、人物与收藏，按照主计划处理物资。研究试剑与普通实验室使用独立来源身份，重放和预览不发永久奖励。

## 十四、如何验证这个系统

当前只有设计与手算，以下全部是后续验收项。

### 14.1 首个原型范围

一个玩家、一个敌人；三种基础姿态；三项资源；六门先行武学；均衡武者、高架势守卫、蓄震守卫三类敌人；一把无特性朴剑；留力、优先级、回合单步／自动；因果记录与同输入重放。

先不加入全部锻造、药材和剧情，只保留其合法输入／保存边界。六门先行版不等于十二门完整 MVP 或生活系统已经完成。

### 14.2 必需规则用例

- 两种出手先后下架招都及时生效，不额外赠送基础攻击。
- 格挡仍可触发默认基础接触起势，完全闪避不触发；多击不会被起势限次压成一击。
- 防御响应先于出手方跨武学追击，冻结不取消合法反震。
- 原响应批不被新回气派生的候选插队，后续批次与优先级可解释。
- 三连致死时停止后续打击，败退方不再获得收势回气。
- 破绽不在本轮末无故消失，不复制、不刷新；基本破绽击和自动追击只消费同一份一次。
- 回气与内力竞争、留力底线、失败支付和零实际变化均记录正确。
- 自身／对方、两门同组件武学和镜像的限次身份正确。
- 回合准备、已用基础行动、冻结保护窗口、待消费状态与未完施放都具有明确阶段。
- 安全边界保存含双方资源、构筑版本、意图、姿态、变招次数、状态、限次、随机状态、下一行动阶段和奖励 ID。
- 各类回气／反击环终止，超限没有伪造胜利、奖励或正常完成。
- 段落交界在固定时点抽取，同种子同输入得到同一段落序列；冻结跳过照常推进段落；具名课题只循环开场段落。
- 词缀只改公开参数，结算中能标出来源；寒体下的冻结阈值与保护期上限正确。

### 14.3 可玩性验证

先检验玩家能否在第一次试玩中解释一次敌招、一次成功接招和一次停招原因；是否会因为反震或留力问题主动改一次武学。

再按共同容量、品质和起始条件验证三条构筑在不同敌人上各有用途。至少观察连续两轮的攻守、内力与击败时机取舍；若每轮只需点击预览中即时伤害最高的按钮，应调整资源与敌招节奏。固定输入用于复现敌人段落和决策；不依靠隐藏的基础命中骰子制造变化。具名课题只循环开场段落，只改种子不会产生新样本；正式遭遇的种子决定段落序列，首阶段按场景／策略矩阵使用预先固定的种子组，见[执行契约](wulin-phase1-contract-v1.1.md)。

批量模拟、真人试玩、普通战斗轮数、组件价格的平衡与敌人可达性均尚未验证。通过这些检查之前，不把“借鉴了著名游戏”当成已经好玩的证明。
