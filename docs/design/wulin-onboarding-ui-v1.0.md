# 《武林·自创绝学》新手教学与界面流程 V1.0

**日期：2026-10-26（UTC）**

配套 [主计划 V1.7](wulin-self-created-arts-v1.7.md)、[战斗规则](wulin-combat-system-v1.0.md)、[成长经济](wulin-progression-economy-v1.2.md)、[敌人配置](wulin-enemies-v1.0.md)、[组件价目](wulin-components-v1.0.md) 与 [规则模拟器契约](wulin-phase1-contract-v1.0.md)。本文件仅完善策划和文字线框；没有制作页面、游戏代码、原型或试玩。10 分钟读懂基本敌招、20 分钟首次改良是待验证的教学目标。

## 一、教学要让玩家获得什么

教学结束时，玩家应能解释一次敌招、一次接招和一次停招，并愿意改一处武学再战。首次改良是“改变用途并看见代价”，不承诺改后所有指标都更高。

- 开场只有断势击与归息诀两门，铁剑，四武学位与容量上限 12；不把基本排序、攻守调息或留力藏在研究等级后。
- 借力诀、叠寒剑、崩势追击、踏风步按已有来源逐项取得，教学不在开场替玩家装好六门。
- 每课只突出一个问题，既有出招／架招／调息仍可选。推荐动作只作提示，不在错误选择后撤回已经发生的战斗结果。
- 教学战斗与正式历练使用同一规则；差异只在明确显示的实验输入、结束条件和奖励身份。
- 可随时离开教学，在据点查看已学内容或进入当前已开放的基础路线；未学课题始终免费补做。

## 二、实验输入、授业与重试的共同边界

### 2.1 教学实例的统一定义

下文资源格式为“气血／内力／架势”；均是该课开始、轮初自然恢复之前的当前值，最大值另列。所有角色使用默认玩家先手、零留力、零初始护势／身法／寒意／破绽。每课从公开的敌人周期项开始，不靠后台修改意图。

课程检查点是已有模板的教学快照，不是另增世界敌人种类或可反复领赏的遭遇。输入面板显示“教学演练”；复位恢复该课固定输入，不能把实验生命、内力、状态、临时装备和回合写回正式人物。

| 检查点 ID | 固定敌方输入与来源 | 周期与技能 |
| --- | --- | --- |
| `fixture_intro_balanced_v1` | 复用 `balanced_tutorial`：气血 18／初气 6／架势 12，最大气血 18、内力 20、架势 12；铁剑 4／4 | 出招接断势 → 架招 → 调息；只装断势击，容量 4，从第 1 项开始 |
| `fixture_breath_balanced_v1` | 同上，固定从第 2 项开始；只改变明确的周期起点 | 第 2 项架招 → 第 3 项调息 → 第 1 项出招接断势，循环 |
| `fixture_cold_example_v1` | 沿用战斗规则 §11.1 的练习窗口：气血 30／初气 8／架势 10，最大 30／20／10；铁剑 4／4 | 只做基础出招，无装备武学、护势或其他被动，容量 0；循环普通出招 |

`fixture_cold_example_v1` 把玩家初气设为 8，轮初恢复后为 10，才与手算“初始已含自然恢复的内力 10”一致；不能再额外发一笔 2。其简化对手明确没有蓄震，也不能把该场实验当作真实路线击败标准敌人。

### 2.2 课题状态与去重

每课保存“未开始／进行中／条件已完成／授业已结算”；去重键为存档内的稳定教学 ID 和对应授业 ID，不含新战斗、随机种子、重试或播放次数。一次合法条件在安全边界确认后即可结算对应授业，不因为之后战败撤销，也不伪造获胜。

| 授业 ID | 公开条件 | 一次成果 |
| --- | --- | --- |
| `grant_chase_intro_v1` | 教学内已有手段实际造成一次敌方架势崩溃 | 崩势追击完整模板初识 |
| `grant_counter_intro_v1` | 教学内自身实际格挡一次 | 借力诀完整模板初识 |
| `grant_cold_intro_v1` | 同一资源教学实际执行过出招与调息 | 叠寒剑完整模板初识 |
| `grant_step_intro_v1` | 打开蓄震公开反应说明，完成指定一整轮教学演练 | 踏风步完整模板初识；不要求获胜或先会闪避 |
| `grant_edit_intro_v1` | 已知断势与叠寒，确认过真实破势事实和蓄震课一轮，进入公开的单槽授业课 | 断势击、叠寒剑精通权限及指定主招组件；不授化境，不代填普通九点证据 |

课程成功不发银两、材料、路线赏金或普通研究点。授业保存独立记录，普通研究仍需正式来源事实或具名研究课题。重试、回看、导入重复快照和更换名字均不能重发教学成果。

### 2.3 失败、跳过与恢复

- 战斗失败后保留已确认的教学事实和一次授业；提供“按本课输入重试”“看关键原因”“回据点”，不收药费、不掉正式库存。
- 中途离开或异常关闭恢复最近安全边界；尚未确认的半轮事实不结算。已经结算授业按 ID 保持，不通过重新播放再领一遍。
- “退出引导”结束提示，不自动授予尚未满足条件的武学或研究等级。未完成内容列在据点“免费补课”，可直接进入所需微课。
- 已满足条件者可跳过重复说明，成果仍只结算一次；不会强迫玩家为拿踏风而故意挨一次反震。
- 普通实验重放与教学身份分开，查看旧战报不能触发授业。演示自动播放可以说明规则；需要实际行动的条件仍由玩家本人操作的课题取得。

## 三、九个教学步骤

时间是首轮测试假设，阅读速度、主动探索和失败都可延长；没有倒计时或超时罚则。前六步争取在约 10 分钟内完成，改良和对照争取在约 20 分钟内完成。

### 3.1 首份改良的解释口径

三连改为单次破势后，蓄震触发风险下降，削架势方式改变；每次主招可施加寒意的接触次数减少，冻结变慢，直接气血输出也可能下降。按当前 [组件价目](wulin-components-v1.0.md)，原版是连击乙内力 3／容量 4＋寒劲 1／2，合计内力 4／容量 6；改良版是破势甲 3／4＋寒劲 1／2，也为 4／6。两版总价相同仍必须逐项复算，差异来自打击与状态作用，不免费赠送附加劲力。改良版沿用来源的剑类限制。

两版加归息后的装配均为容量 8。按上述固定首轮、两者均选择出招的独立手算：

| 指标 | 原三连寒劲 | 单次破势寒劲 |
| --- | --- | --- |
| 玩家回合后气血／内力／架势 | 24／8／20 | 30／8／20 |
| 敌方回合后气血／架势 | 21／10 | 28／8 |
| 反震 | 三连三次接触，引出威力 6 的一次反击 | 付费主招只有一次接触，不触发蓄震 |
| 控制结果 | 三次积寒清空，冻结待跳过其下一行动；本轮架招已用不能撤回 | 积寒 1，尚未冻结 |

这些只是规则演算，未运行模拟。它说明改良版少受反震、削架势略多，同时直接伤血较低、控制较慢；不能只突出“少掉 6 血”并藏起损失。

A/B 比较从相同输入重新开始；不能把 A 先打掉敌人气血的状态接着给 B 使用。若某个结果需要两轮才体现，允许将两版都延长到相同轮数与相同决策序列，再明确展示分歧来源。

“保存草稿”“保存改良版本”“装备此版”是三个动作；保存不自动替换正在用的版本，不覆盖原书。允许同名不同版本，列表同时显示版本号和来源；命名不改变武学、研究或奖励身份。空名提供可编辑默认名，长名提示调整，不因命名卡住教学。

### 3.2 从教学到正式人物

教学结束同步的只有已确认授业、教学完成标记、合法保存的秘籍版本与玩家选择的长期目标。真实钱包、库存、人物、路线和研究证据不被教学快照覆盖。

在 Phase 2 独立实验室，秘籍保存属于实验资料，界面标注“实验版本”；没有真实路线或钱包。Phase 3 以后才接正式人物，已取得成果按固定来源一次导入；不把早期实验记录伪装成已经完成的江湖经历。

每个技能是否已经学会、是否已精通、是否仅有实验版本独立显示。离开教程不丢书；正式出发时重新校验当前武器标签、四槽、容量和内容版本，不能携出实验中临时不合法的配置。

### 3.3 后期武学的公开课题

回身、养元、守拙不混入首次九步教程，其固定对手、初始资源、装配、留力、完成条件和一次授业 ID 见[成长细则第四章](wulin-challenge-progression-v1.0.md)。它们复用同一套课题入口、失败重试与去重机制；界面在入场前明确列出专项条件，不把奖励武学临时借给首次挑战。

## 四、主要界面与前后关系

核心路径为“据点目标 → 构筑与准备 → 敌人预告 → 逐轮选择 → 结果与改良方向 → 据点”。研究、收藏和详细记录从对应位置进入，不要求玩家每轮来回切换页面。

### 4.1 据点与出发

```text
江湖手稿                  当前目标：验证单击改良能否减少反震
人物／医案：旧伤已稳定     下一线索：保留给下次出门

[继续未完历练] [选择新路线] [武学与改良] [补给与工艺] [免费补课]
路线：基础短途    工具：采药包    药品：0 / 2
已知风险：两次交锋；途中有安全整备节点
出发检查：武学 3 / 4，容量 10 / 12，铁剑
[查看缺口与来源] [出发]
```

路线详情只显示已公开的风险、节点与奖励来源。配方缺料可跳到商店／已有采集线索，返回后保留整备草稿。矿镐与采药包互斥，药品总数两剂；不能把“库存很多”显示成全能随身携带。

有进行中历练时优先“继续”；另开路线先明确当前撤回与物资处理结果，不能静默抹掉历练。退出整备不扣银两和材料，制作／购买另有真实一次事务。

### 4.2 武学、研究与改良

1 断势击      已精通       [查看接招] [改良]
2 崩势追击    初识         [查看来源] [研究线索]
3 归息诀      初识         [查看作用]

四研究等级显示已开放能力和下一条可追踪条件，不用一条“经验条”暗示无限刷怪。教学授业单独标记，不能显示为伪造的普通研究点。研究页面逐项区分“有效一次”“两类敌人证明”“改良验证”“化境验证”，点开即可看到来源与待做课题。

组件不兼容时说明哪一槽、哪个标签、如何恢复合法；超容量时列清武学和兵器各占多少。保留不合法草稿可供修改，但不能装备、出发或冒充已验证绝学。化境前五槽区域可查看说明，只有已获权限的单槽可编辑。

### 4.3 看招与逐轮承诺

以下为信息布局示意，不是某个已经模拟通过的对局。

```text
第 2 轮   玩家先手                 [逐轮] [自动策略] [暂停]
我方：气血 30 / 30  内力 10 / 20  架势 20 / 20
敌方：蓄力刀客  本轮出招
  基础：6 气血 / 2 架势
  若基础接触：沉刃斩 12 / 6，付内力 5
  若打崩我方架势：可能接崩势追击
  说明：一层护势只保护一门主招。下个公开窗口：普通出招。

[1 出招] [2 架招] [3 调息]     留力：0     变招：2 / 2
选择后的预览：按当前输入逐项展示；条件追击单独标明。
[确认本轮] [查看因果] [变招]
```

选姿态先更新预览，确认后锁定；播放期间重复点击不插入第二个行动。自动模式只在下一决策边界接管，暂停也在该边界生效；不要求抢动画帧。变招显示本轮临时影响及两次额度，基础姿态选择不扣次数。

本轮预览使用状态副本；不会扣内力、药品或研究，不推进正式敌人周期。确定性部分必须与实际结算一致；没有声明的未来随机内容不显示成确定结果。主招分段显示，避免把“本轮架招”误读为整条连锁都减半。

### 4.4 因果与停招原因

默认只保留能解释结果的几行，按需展开资源与详细事实。

```text
基础出招接触
  → 叠寒剑：支付 4，三次接触
  → 敌方蓄震：支付 2，按三次接触反击威力 6
  → [若真实产生崩溃] 崩势追击：检查现有内力与留力

停止：付款后会低于留力 4。未付款，未消费破绽，没有追击回气。
[查看付款前资源] [查看触发来源] [回到本轮摘要]
```

停招原因至少区分：内力不足、低于留力、目标已败退、起势未成立、状态已存在无增量、每根／每轮次数已用、组件不兼容及诊断上限。不能把所有情况写成“发动失败”。基础出招被闪避时说明“没有接触，所以未获得该技能机会”；不是技能已经发动再被系统取消。

安全上限、决策不足、版本不兼容不能显示成普通平局或胜利，也不发奖励。详细事件 ID、根和规则版本放在展开的诊断区；普通玩家主要看到武学、动作、资源和原因。

### 4.5 战后、目标与再战

战后先显示胜负、消耗和关键原因，再显示本次真正结算的研究、人物与物资。失败保留哪些事实、损失哪些未入库材料、哪些奖励没有取得必须清楚区分。

最多推荐两项可选的实验方向，例如“比较单击主招”“看看身法能否处理反震”；不给一键生成必胜功法。玩家可以原样再试、改良、查看图鉴或归馆，不因没按建议走而被阻挡。

对照记录同时显示敌人配置、初始资源、兵器、武学版本、留力与决策序列。不同条件下的数字可查看，但提示“条件不同”，不直接标成新版本更强。

## 五、保存、导入与错误状态

保存接口和正式版本导入由对应阶段实现；本表是交互要求，不代表当前已可存档。

| 状态 | 玩家看到什么 | 后续行为 |
| --- | --- | --- |
| 正常退出 | 正在等待本轮结算边界；保存后退出 | 不停在半个伤害事件中伪造完整存档 |
| 自动保存失败 | 最近成功保存的时间／轮次，本次未成功；当前对局仍保留在内存 | 提供重试和当前安全快照导出，不能显示“已保存” |
| 文件损坏或不是本作存档 | 无法读取的明确原因；当前进度未替换 | 回到原页面、重选文件；不清空旧进度 |
| 内容／规则版本不兼容 | 哪份秘籍或对局暂不能按现规则恢复 | 保留原文件与可读记录；有已验证迁移才提供迁移选项 |
| 导入会替换正式进度 | 显示现有与导入的日期、人物／路线及差异 | 先提供备份，再由玩家确认替换；取消保持原进度 |
| 空名、过长名、同名不同版本 | 输入边界或版本提示 | 提供默认名、修改与版本编号；不靠名字识别研究与奖励 |
| 超容量或缺组件 | 哪几项导致不合法，以及当前可改项 | 保留草稿；装备／出发前阻止使用，不丢弃原版本 |
| 预览与实结算不一致 | 对局和输入已保留，提示规则异常 | 停止自动推进，允许查看记录；不能自动重算发一份新奖励 |

导出文件与旧回放不自动变成可领取奖励的正式世界。多次导入同一存档只恢复其中已确认的结算身份，不重新发起始银两、教学、医案或工艺包。

## 六、输入、可读性与视觉反馈

- 鼠标和键盘都可完整操作：`1/2/3` 选择姿态，`Enter` 确认，`Esc` 关闭详情／返回；输入框与弹窗获得焦点时不触发战斗快捷键。排序同时提供拖动与上移／下移按钮。
- 已选姿态、焦点与确认状态可见；重复按键不反复承诺同一轮。自动暂停键只影响下一合法决策窗口。
- 状态同时使用名称、图标与数字，不只靠红绿区别。气血、内力、架势显示当前／上限；寒意显示层数及冻结保护说明。
- 文本可调大，长武学名和多段敌招换行，不用必须悬停才能读到的关键提示。减少动态效果后仍能辨认先后、来源、资源与结果。
- 战斗特效和回放可加速／跳过表现，规则结果不变；跳过动画仍保留关键摘要。没有完成授业条件的演示不能因“看完动画”自动结算。
- 低分辨率时先保留三资源、敌方意图与三个基础操作，详情折叠；不追求把编辑器、图鉴和完整战报同时塞进战斗屏幕。

## 七、教学与界面的验收观察

| 问题 | 观察方式 | 失败信号与调整方向 |
| --- | --- | --- |
| 读懂敌招 | 首轮约 10 分钟内让玩家说明“它先做什么，后续需要什么条件” | 只看总伤害、不理解追招：拆开主招与条件说明 |
| 首次改良 | 约 20 分钟内完成单槽、保存命名、同条件复战 | 找不到改造入口或被术语卡住：减少首课选项，保留原版与收益代价 |
| 因果理解 | 问一次反震、停招或护势为何结束 | 误以为技能随机失灵：突出真实触发与资源账本 |
| 成长理解 | 玩家能区分“新学会”“教学授精通”“普通研究证据” | 认为看回放就能刷满研究：改来源标签和结算摘要 |
| 自主实验 | 玩家提出并尝试教程之外的一项改造假设 | 只照着高亮点完：降低强制引导，增加可比较的真实得失 |
| 无软锁 | 不看完整教程、药品为零、未专精生活、先失败后重试等路径均可继续 | 必须拥有本课奖励才能过本课：改前置和固定输入 |
| 完整可操作 | 键盘、放大文本、减少动态效果均能完成主流程 | 关键敌招只能悬停、按钮不可见：调整布局与焦点 |
| 保存可信 | 正常退出、保存失败、坏文件、旧版本导入和取消替换都有明确结果 | 提示成功但实际丢进度，或重新导入重复发奖励 |

首次可用原型再用少量真人观察记录问题。上述时间、理解度与操作流畅度是设计目标，不能依据本文件宣称已经通过教学或可玩性验证。
