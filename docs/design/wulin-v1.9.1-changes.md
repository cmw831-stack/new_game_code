# 《武林·自创绝学》V1.9.1 修订说明

**日期：2026-10-26**

**起因：** 负责人试玩构筑实验室 M1 后反馈“好像只要选出招都会胜利”。V1.9 矩阵中，9 个构筑×敌人组合有 7 个“始终出招”胜率 100%。

**依据：** [调参实验 3 报告](../reports/phase2-experiment-3-report.md)

**负责人决定（2026-10-26）：** Q8 均衡武者定为教学对手；Q9 接受蓄震守卫克制寒霜连锁；Q10 把实验 3 的 X14 写进 V1.9.1 并更新试玩网页。

## 一、改了什么

| 改动 | 文档位置 |
| --- | --- |
| 高架势守卫气血 43 → 52 | 敌人细则 V1.3 第 4.1 节 |

## 三、标准的修订

实验 3 预先写定的标准是“每套构筑至少 2 类敌人满足：一直出招胜率 ≤ 50%，其余打法中最好的一种 ≥ 80%”。按这个标准，X14 没有通过，因为寒霜连锁只有 1 类敌人达标。负责人按 Q8、Q9 决定：把均衡武者排除在这条标准之外，并接受蓄震守卫对寒霜连锁的克制。在修订后的标准下，其余 6 组中 5 组达标。这是看过结果后才修改的标准，在此如实记录。
