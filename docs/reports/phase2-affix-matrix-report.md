# 词缀矩阵报告：首批六个词缀是否改变了题目

**日期：2026-10-28**

**依据：** [敌人细则 V1.3](../design/wulin-enemies-v1.3.md) 第 9.2 节（首批六个词缀，首轮提案、待验证）、9.3 节（验证要求）；Phase 2 方案 M4“在矩阵中加入词缀维度”。

**原始数据：** [词缀矩阵数据](phase2-affix-matrix-data.md)（`npm run affix-matrix` 生成）。三套先行构筑 × 三类标准敌人 × 四种打法 × 20 个固定种子；每个词缀单独加上，与无词缀对照。

**运行前写定的判定：**

1. 改变题目：至少一格（构筑×敌人×打法）胜率比无词缀下降 20 个百分点以上。（9.3 节：“至少有一个词缀能让它的胜率明显下降；否则说明该词缀没有改变题目”）
2. 保留解法：带词缀的每类标准敌人，仍至少有 2 个“构筑×打法”胜率 ≥ 80%。（9.3 节：“至少保留两条当前可达解法”）
3. 没有非正常结束。

## 一句话结论

**六个词缀里只有“身轻”通过。** 其余五个都没能让任何一格胜率明显下降：铁衣、厚气对这三套构筑完全没有影响；寒体、重手的补偿比效果大，反而让对手变弱；伤疲本来就是“较轻松的遭遇”。所有词缀都保留了足够解法，也没有非正常结束。

## 一、结果

| 词缀 | 改变题目 | 实际影响（只列有变化的格） | 保留解法 |
| --- | --- | --- | --- |
| 寒体 | 否 | 只有变易：高架势守卫、蓄震守卫面前防反、破势的胜率上升（气血 −10% 的补偿起作用） | 是 |
| 铁衣 | 否 | 没有任何一格变化 | 是 |
| 重手 | 否 | 只有变易：破势打高架势守卫 95%→100%；防反打蓄震守卫守反、谨慎读窗口 55%→100% | 是 |
| 厚气 | 否 | 没有任何一格变化 | 是 |
| **身轻** | **是** | 防反打蓄震守卫：始终出招 45%→25%，读窗口 100%→80%；但寒霜连锁打高架势守卫“始终出招”35%→85% | 是 |
| 伤疲 | 否（设计如此） | 全部变易，例如寒霜连锁打蓄震守卫从 0% 到 80% | 是 |

均衡武者面前，六个词缀都没有改变任何一格。三套构筑对它本来就几乎全胜。

## 二、为什么

- **天花板和地板：** 很多格无词缀时已经是 100% 或 0%，词缀的小幅修正改变不了结果。例如寒体针对寒霜连锁，但寒霜连锁打均衡武者、高架势守卫本来就用读窗口全胜，打蓄震守卫本来就全输。
- **补偿大于效果：** 寒体的“要 4 层寒意才冻结”只在恰好积到 3 层时有影响，而气血 −10% 每场都生效。重手的“气血威力 −1”比“架势威力 +2”影响更大。
- **矩阵里没有被针对的打法：** 厚气针对“指望耗尽对手内力的打法”，铁衣针对“破势爆发”，三套预设构筑里都没有真正依赖这两点的打法。
- **身轻的缺口：** 身轻让高架势守卫开场就闪开第一轮的攻击，却也少了 2 点架势上限，寒霜连锁“一直出招”反而更容易赢（35%→85%），削弱了 V1.9.1“一直出招会输”的目标。
