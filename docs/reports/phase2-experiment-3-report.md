# Phase 2 调参实验 3 报告

**日期：2026-10-26**

**起因：** 负责人试玩 M1 后反馈“好像只要选出招都会胜利”。核对 V1.9 矩阵：9 个构筑×敌人组合里，有 7 个“始终出招”胜率 100%。

**原始数据：** [实验 3 数据表](phase2-experiment-3-data.md)（`npm run experiment3` 生成）。起点是 V1.9 默认值，所有改动只在内存中生效。

## 一句话结论

**14 个变体都没有通过预先写定的标准。** 统一加强所有敌人，会先打垮开局两门，再让一些对局变得怎么打都赢不了，“一直出招会输、看意图能赢”的组合却增加得很少。按敌人分别调整的 X14 最接近：9 组里有 5 组达到“一直出招会输、看意图能稳赢”，开局两门的首节点保底也保住了。没通过的原因只有一个：寒霜连锁只有 1 组达标。

## 一、标准（运行前写定）

1. 每套构筑至少在 2 类敌人面前，“始终出招”胜率不高于 50%，并且其余打法中最好的一种胜率至少 80%；
2. 开局两门（断势＋归息）用“读窗口”或“谨慎读窗口”打均衡武者，不带药至少 18／20 胜；
3. 没有非正常结束。

这次另加了第四种打法 **“谨慎读窗口”**：敌人出招时架招，敌人调息时出招，敌人架招时调息，而不是攻进去。

## 二、结果

| 变体 | 改动 | 达标组合（共 9） | 开局两门首节点（读窗口） |
| --- | --- | ---: | ---: |
| X1 | 无（V1.9） | 1 | 20／20 |
| X6 | 所有敌人基础出招 +6，均衡武者再 +3 | 3 | 4／20 |
| X12 | 同 X6，并给均衡武者、蓄震守卫加借力反击 | 3 | 0／20 |
| X13 | 高架势守卫气血 ×1.2 | 3 | 20／20 |
| **X14** | **高架势守卫气血 ×1.2；蓄震守卫气血 ×1.2、基础出招再 +9** | **5** | **20／20** |

**X14 每组的结果：**

| 构筑 \ 敌人 | 均衡武者 | 高架势守卫（52 血） | 蓄震守卫（48 血） |
| --- | --- | --- | --- |
| 寒霜连锁 | 始终出招 100%；读窗口 100% | 始终出招 35% → **读窗口 100%** ✓ | 所有打法 0% |
| 防反 | 始终出招 100%；读窗口 100% | 始终出招 45% → **守反为主 100%** ✓ | 始终出招 45% → **读窗口 100%** ✓ |
| 破势 | 始终出招 100%；读窗口 100% | 始终出招 0% → **守反为主 95%**（23.5 轮，剩 2 血） ✓ | 始终出招 0% → **读窗口 100%** ✓ |

## 三、发现

### 1. 统一加强敌人行不通

均衡武者是基础路线第一个节点的对手。只要把它调强到能让成熟构筑“一直出招”输掉，开局只有两门武学的新玩家用任何打法都打不过它。新手保底和“一直出招会输”在同一个对手身上无法同时成立。

### 2. 按敌人分别调整有效

- **高架势守卫：** 只加气血（43→52）就够了。它架招时会借力反击，硬攻会被反击打穿，看意图在它调息时出手才能赢。三套构筑全部达标。
- **蓄震守卫：** 需要让它出招更重（基础出招 7→16，被护势减半后为 8），不架招的代价才足够大。防反、破势达标。

### 3. 寒霜连锁打不赢蓄震守卫

X14 下，寒霜连锁打蓄震守卫，四种打法都是 0%。蓄震本来就是专门惩罚多段攻击的对手。只看这一组是“打不赢”，但放到整个游戏里，这正是策划书想要的循环：输给蓄震 → 发现是三连吃反震 → 改用单次破势的改良版，或换构筑 → 再打。

### 4. 还没解决的

- 破势打高架势守卫只能靠守反硬磨 23.5 轮，最后只剩 2 血，太长也太险。
- 均衡武者面前，三套构筑“一直出招”仍然全胜。

## 四、需要你决定

| 编号 | 问题 | 推荐 |
| --- | --- | --- |
| Q8 | 均衡武者是新手首节点的对手，是否允许它被“一直出招”打赢？ | **允许。** 把它定为教学对手，“一直出招会输”的标准只用在其余对手上 |
| Q9 | 是否接受蓄震守卫完全克制寒霜连锁（不改构筑就打不赢）？ | **接受。** 这正好对应“输了改一处再打”的核心循环；Phase 2 的 M2 会提供单槽改良，让玩家有路可走 |
| Q10 | 是否把 X14 写进 V1.9.1，并更新试玩网页？ | **写入并更新。** 这样你再试玩时，打高架势守卫或蓄震守卫“一直出招”大多会输，看意图打则能赢 |

如果三项都按推荐，这轮实验在修订后的标准下算通过：均衡武者之外的 6 组里有 5 组达标，未达标的 1 组是第 3 点说明的克制关系。修订标准这件事会如实写进 V1.9.1 修订说明。

## 五、局限

- 打法仍是写死的规则，真人可能找到更好或更差的打法。
- 破势对高架势守卫过长的问题没有处理。
- 疾步剑客、蓄力刀客还没有进入矩阵。
