# M3 第一步：十课教学按 V1.9.1 规则走查

**日期：2026-10-28**

**依据：** [教学细则 V1.2](../design/wulin-onboarding-ui-v1.2.md) 第二、三章。V1.2 开头写明“第三章各课需要按新规则重新走查”，本报告就是这次走查。

**原始数据：** [走查数据表](phase2-m3-lesson-walkthrough-data.md)（`npm run walk-lessons` 生成）。课程定义在 `src/teach/lessons.ts`，测试在 `test/lessons.test.ts`。

**方法：** 战斗课按 2.1 节的检查点建立固定输入（检查点只循环开场段落，结果与种子无关）。每课先按文档建议的姿态打，看第几轮完成；再穷举前 4 轮全部 81 种姿态序列，统计完成、败退、先打赢、仍在进行的情况；对仍在进行的局面，再穷举之后 6 轮，看是否已经不可能完成。

## 一句话结论

**六门战斗课在 V1.9.1 下都能按建议 1–2 轮完成，任何打法都不会在完成前败退。** 不需要改任何课的配置或数值。发现两处需要界面提示的情况，以及两处文档措辞已过时；另有一处范围问题需要你决定。

## 二、发现

### F1 先把对手打赢，课就结束了（架招课 6／81，调息课 4／81）

两课的教学对手只有 18 气血。玩家一直出招，三轮就能打赢，但没做到本课要求的格挡或调息。按 2.3 节，这时课没有完成、也不发授业，可以按本课输入免费重试。

**处理：** 不改配置。结果页在“本课目标还没完成”时明确说出来，并把“按本课输入重试”放在最前面。

### F2 架招课：内力已满时归息诀没有收益（4／81 会走进只能重试的局面）

教学对手每三轮才出招一次，玩家架招轮之间的轮初回气会把内力补满，格挡时归息诀没有可回的内力（文档要求“回气需要真实增量”）。要完成，得在对手出招的前一轮先出招花掉内力；但如果对手已经很残，这一下出招会直接打赢，课就只能重试。

**处理：** 不改配置。本课在内力已满时给出提示：“内力已满，归息诀格挡后没有可回的内力。先出招花掉一些，在对手出招那一轮架招。”
