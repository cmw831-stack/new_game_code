## 六、设计目标核对（机械判定）

- 寒霜连锁：在 3 类标准敌人上有可复现的胜利（均衡武者、高架势守卫、蓄震守卫）。目标至少 2 类：达到。
- 防反：在 3 类标准敌人上有可复现的胜利（均衡武者、高架势守卫、蓄震守卫）。目标至少 2 类：达到。
- 破势：在 3 类标准敌人上有可复现的胜利（均衡武者、高架势守卫、蓄震守卫）。目标至少 2 类：达到。
- 构筑排名在不同敌人间没有出现交换：均衡武者 寒霜连锁 > 破势 > 防反；高架势守卫 寒霜连锁 > 破势 > 防反；蓄震守卫 寒霜连锁 > 破势 > 防反。
- 非正常结束（轮数上限、安全上限）共 0 场，占 0%。
