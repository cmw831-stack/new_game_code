# Phase 2 试玩包：说明与观察表

**日期：2026-10-28**

**依据：** [Phase 2 方案](phase2-lab-plan.md)第一节（试玩要回答的问题与指标）；[主计划 V1.9.1](../design/wulin-self-created-arts-v1.9.1.md) 13.5 节（真人试玩指标）；[教学细则 V1.2](../design/wulin-onboarding-ui-v1.2.md)第七章（验收观察）。

**用途：** 第一部分发给试玩者；第二、三部分是负责人观察时用的。约 5 位不参与开发的试玩者，每人约 30 分钟。小样本只用来找问题，不据此宣布“已验证”或“好玩”。

---

## 一、给试玩者的说明（可直接转发）

> 这是一个武侠战斗的实验版，只有文字和简单界面，还很粗糙。想请你玩大约 30 分钟。
>
> 1. 打开链接，首页点“开始第一课”，按课程往下走。哪里看不懂、卡住了，**直接说出来**，边玩边说你在想什么最有帮助。
> 2. 课程可以随时离开，之后再补。打输了也没关系，输了之后你想怎么办，正是我们想看的。
> 3. 课程走完后，到首页自己组一套武学，挑一个对手打几场；想改武学可以去“武学工坊”。
> 4. 结束前，在首页最下面点“导出试玩记录”，在弹出的确认里选保存，把下载的文件发给我。记录只有你的选择和战斗结果，没有个人信息。
>
> 用电脑浏览器最方便；键盘 1／2／3 选出招、架招、调息，Enter 确认。

## 二、观察表（每位试玩者一份）

试玩者代号：＿＿＿　日期：＿＿＿　设备／浏览器：＿＿＿　是否玩过类似游戏：＿＿＿

**规则：** 只记看到的行为和原话，不提示、不解释（除非对方完全卡住超过 2 分钟，并记下提示了什么）。时间从打开链接算起。

| # | 指标（来源） | 目标 | 观察方法 | 实际时间／结果 | 原话或现象 |
| --- | --- | --- | --- | --- | --- |
| 1 | 基本理解（方案第一节、13.5 节） | 10 分钟内 | 首战后问：“对手这一轮要做什么？你出招、架招、调息有什么不同？你的某门武学什么时候会发动、要花什么？” | | |
| 2 | 第一次改良（同上） | 20 分钟内 | 看是否完成单槽改良课并保存版本；问：“改了之后得到什么、失去什么？” | | |
| 3 | 第一次创造（同上） | 30 分钟内 | 看是否补全卷首残页并命名；问：“你选的劲力好在哪、代价是什么？”留意是否随手选第一个 | | |
| 4 | 因果理解（同上；教学细则第七章） | 能说出 | 指着战斗记录问：“这一下为什么发动了？那一门为什么没发动？” | | |
| 5 | 跨轮决策（同上） | 至少两轮 | 问：“刚才为什么这轮架招／调息？有没有故意留内力？” | | |
| 6 | 跨武学连锁（13.5 节） | 主动完成一次 | 看是否不靠课程提示，自己打出一条跨武学连锁（例如寒霜冻结后追击） | | |
| 7 | 失败后的行为（方案第一节） | 提出具体假设再战 | 输了之后，是改了一处再打，还是直接按“重来”？记下他说的理由 | | |
| 8 | 自主实验（13.5 节、教学细则第七章） | 无人提示时尝试 | 课程之外是否自己尝试别的组合、改良或 A／B 对照 | | |
| 9 | 完整可操作（教学细则第七章） | 无卡死 | 是否出现找不到按钮、看不懂提示、不得不问人的地方 | | |

**整体印象（结束时问，原话记录）：**

- “最想再玩一次的是哪一部分？最烦的是哪一部分？”
- “如果再给你 10 分钟，你想试什么？”
