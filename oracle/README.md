# 战斗规则独立参考实现（oracle）

用 Python 3.13 标准库写成的《武林·自创绝学》单场战斗结算，用来和主实现对拍。只依据 `docs/design/` 当前生效版本写成（主计划 V1.9.1、战斗细则 V1.2、组件细则 V1.2、敌人细则 V1.3、执行契约 V1.2、V1.9／V1.9.1 修订说明），输入输出格式见 `docs/engine/oracle-io.md`。编写时没有参考 `src/`、`test/` 等已有代码。

## 运行

```bash
python3 oracle/run.py < case.json > result.json
```

测试（在仓库根目录）：

```bash
python3 -m unittest discover -s oracle -v
```

当前共 31 个测试，全部通过。

## 文件

| 文件 | 内容 |
| --- | --- |
| `run.py` | 组件价表、十二门预设与敌方武学目录、输入校验、逐轮结算；`simulate(case, rules)` 可直接在 Python 中调用 |
| `test_oracle.py` | 验收测试，预期值取自文档手算，测试名与说明注明出处 |
| `AMBIGUITIES.md` | 文档没写清、前后矛盾或必须二选一的地方，以及本实现的选择 |

## 覆盖的规则

- 三种基础姿态：出招（兵器威力，消费破绽 +2）、架招（准备阶段回 4 架势、建基础护势）、调息（行动窗口回 4 内力）。
- 三项资源与上限；轮初双方各回 2 内力；实际增加为零不产生回气事实。
- 先后手：敌方本轮意图为出招时敌方先手，否则玩家先手。
- 护势：基础架招护势锁定敌方整条攻击链（同一根连锁），根结束后消费；技能护势只锁一门主招、主招结束后消费；击前有架势且本轮未崩溃才减半（向下取整），架势伤害照常；闪避的打击不消费护势。
- 一次打击的顺序（战斗细则 5.3）：闪避 → 格挡与破绽 → 提交伤害 → 死亡 → 崩溃、接触劲力、寒意阈值。
- 接触起势（含被格挡的接触）、格挡起势、闪避起势、崩溃起势、内力跨 8、冻结出现。
- 拆招窗口：每门主招（含基础出招）结束后先结清受击方防御响应，再结算出手方收势，再按编排处理出手方跨武学候选；新候选缓冲到下一批。
- 每根每门武学最多成功一次；回气内功与踏风、回身、守拙每轮一次；支付前的“状态已存在／无增量”跳过；内力不足与留力跳过（不扣费、不占限次）。
- 架势崩溃（每轮一次）、破绽归属与过期（按基础行动 ID）、轮末恢复到上限 40%。
- 寒意、冻结、跳过下一次未用的基础行动、冻结保护窗口与保护期寒意上限 2。
- 劲力刚、柔、寒、震；收势伤血回气、复架势。预设没有变化子招，变化组件未实现。
- 身法准备（踏风步、回身步）与闪避；养元功。
- 敌方武学：蓄震诀（按一门多段主招的有效接触数反震）、沉刃斩、沉刃斩·论艺。
- 敌方意图循环与 `disabled`；玩家变招（暂停一门、改优先级、改留力，只到轮末，每战两次）。
- 安全上限：每场 100 轮；每根／每轮／每场事件数与深度（预设内容下实际不会触发）。
- 非法输入：超过四门、容量超过 12、剑专用武学配非剑兵器、未知或重复武学、玩家装备敌方专用武学、资源越界、变招不合法（格式、对象、超过两次）、意图循环不合法。

## 没有覆盖

- 敌人套路段落 B 与段落抽取、战斗种子（IO 格式只给一个固定循环）。
- 敌人词缀、历练题目、药品、兵器特性与兵器费用修正。
- 变化子招（`F_hit_single`、`F_freeze_combo`）、单槽改良、残页、自创组装（IO 只接受预设名称）。
- 自动策略、预览、存档／检查点、因果日志（输出只有每轮快照）。
- 连续遭遇的资源结转（包括开场内力取 min(结转值, 10)，见 AMBIGUITIES A01）。

## 已知差异风险

最可能与主实现不一致的口径集中在 `AMBIGUITIES.md` 第一节：A01（开场内力是否截断到 10）、A03（跨武学候选的批次缓冲）、A08（整链护势的范围与消费时点）、A11（整链护势存在时守拙诀跳过）、A23（破绽过期计数）、A17（IO 示例用了三次变招，本实现判为非法输入）、A31（冻结保护窗口的起止）。
