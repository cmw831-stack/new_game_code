# 武林·自创绝学

> 习百家武学，悟万般变化。
> 不求天下第一秘籍，只创属于自己的绝世武功。

一款 PC 单机独立游戏：玩家继承一部写满失败的武学手稿，拆解百家招式，重组成自己的绝学，再用它救人、铸剑、被人记住。

**当前状态：** Phase 1 进行中。已有无界面的 TypeScript 规则引擎和验收测试，尚无可玩的界面。

## 运行测试

需要 Node 24 或更高版本。

```bash
npm install
```

```bash
npm run check
```

运行 27 格构筑矩阵并生成数据表：

```bash
npm run matrix
```
